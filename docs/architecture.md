# Architecture and Standards

Please refer to the root `README.md` or the `architecture_and_standards.md` artifact generated for comprehensive architectural guidelines of this platform.

**Core Principles:**
1. Domain-Driven Design (4 Clouds: Core, Experience, Identity, Media)
2. Global Shared Utilities
3. Standardized JSON Responses `{status, message, data}`
4. Decentralized Seeding
5. Background Workers & Microservices boundary
